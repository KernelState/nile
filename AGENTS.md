# AGENTS.md — Nile (River fork)

## Stack
- Zig 0.16 + wlroots 0.20 Wayland compositor. Binary is `nile` (`nile/main.zig:154`), not `river`.
- Dependencies declared in `build.zig.zon:13` (pixman, wayland 0.6.0, wlroots 0.20.1, xkbcommon 0.4.0, translate_c). System libs also required: `wayland`, `wayland-protocols`, `wlroots-0.20`, `xkbcommon>=1.12`, `libevdev`, `libinput`, `pixman`, `pkg-config`, optional `scdoc` for man pages.
- `nile/c.h:1` is translated via `translate_c` dep — needs `libevdev` + `libinput` headers at build time.
- Zig package fetch: `zig fetch --global-cache-dir <dir> <url>` per-entry from `build.zig.zon`, then `zig build --system <dir>/p` for offline (see `PACKAGING.md:1`).

## Build / Run / Test
```bash
zig build --help                          # all options
zig build -Doptimize=ReleaseSafe --prefix ~/.local install
zig build -Dxwayland                      # enable Xwayland (off by default, build_options.xwayland)
zig build -Dstrip -Dpie -Dllvm            # other flags in build.zig:16
zig build test                            # only test: common/slotmap.zig (build.zig:211)
zig build run                             # runs compositor — needs Wayland/KMS, not for CI
```
- Typecheck is `zig build` itself (no separate `tsc`); there is no lint/formatter beyond `zig fmt`.
- Single test suite; `zig build test` runs `common/slotmap.zig:124` (`basic` / `iteration` / `remove during iteration`). No integration tests.
- Man pages: built via `scdoc < doc/nile.1.scd` if `scdoc` found; disable with `-Dman-pages=false` (`build.zig:29`).

## Runtime invocation (for manual testing)
```bash
nile -h | -version | -c 'sh -c <command>' | -log-level error|warning|info|debug | -log-scopes all,~wlroots | -no-xwayland
```
Init executable: `$XDG_CONFIG_HOME/river/init` or `~/.config/river/init`, must be executable or startup is skipped (`nile/main.zig:222`). Init containing `riverctl` is rejected — Nile has no `riverctl` protocol (`nile/main.zig:247`).

## Architecture
- Entrypoints: `nile/main.zig:44` (arg parse, `server.init`, `NileCompositor` registration, Wayland socket, init fork) → `nile/Server.zig` (global `pub var server: Server` in `nile/main.zig:42`, accessed as `&@import("main.zig").server` in `nile/Nile.zig:57`) → `nile/NileCompositor.zig` (default arrange).
- Public API: `nile/Nile.zig:1` — `Nile.Window` / `Nile.Output` / `Nile.Seat` / `Nile.Input` / `Nile.Layer` thin façades over `Window.zig`, `Output.zig`, `Seat.zig`, etc. All six `river_*_v1` Wayland protocols + XML have been removed; `protocol/` now only has `protocol/upstream/` wlr protos.
- Transaction model: mutate `wm_requested`/`rendering_requested` via `Nile.*` then call `Nile.dirtyWindowing()` (windowing/configure) or `Nile.dirtyRendering()` (position/hidden/borders/clip) — flushed on next idle (`doc/nile-api.md:43`). See `WindowManager.manageStart/manageFinish/renderStart/renderFinish`.
- Event system: `nile/Compositor.zig:57` — implement `handle(self: *T, event: Event) void`, register via `Nile.setCompositor(Compositor.initCompositor(T, &inst))` (`nile/Nile.zig:101`) or `Compositor.set`. Events delivered on Wayland thread; `window_add` queued (max 32, `Compositor.zig:189`) if no compositor registered yet.
- State handles: `Window.Ref` is a `common/slotmap.zig:8` `SlotMap` key — store `Ref`, not `*Window`, for long-lived handles.
- Common helpers: `common/slotmap.zig` (generational map), `common/flags.zig` (used in `nile/main.zig:59`).
- Wayland globals generated by `wayland.Scanner` in `build.zig:76` — system protocols (xdg-shell, ext-session-lock, etc.) + `protocol/upstream/wlr-*.xml`. Versions are Zig-codegen only; wlroots internals unaffected.

## Layout

## Style & Workflow
- Format: `zig fmt` before every commit (`CONTRIBUTING.md:52`). Editor: run on save. Config: ` indent_size=4` for `*.zig`, `2` for `*.xml`/`*.yml`, tab for `*.scd` (`.editorconfig:1`). 100 columns soft limit; use trailing comma to force wrapping.
- Extra rule: never multi-line `if` without braces — `if (foo) bar();` or `if (foo) { bar(); }` (`CONTRIBUTING.md:59`).
- Commits: `Prefix: summary` — e.g. `build: add -Dxwayland option`, `Window: fix …` (`CONTRIBUTING.md:24`). History should be clean; see weston guidelines link in CONTRIBUTING.
- Upstream River forbids AI contributions; Nile is a fork — that policy does not apply here, but keep commits descriptive for human review.

## Gotchas
- `zig build` requires `wlroots-0.20` pkg-config (`build.zig:137`) and Wayland server headers; compiling without them fails at `translate_c` / `wlroots` module step, not at Zig syntax.
- `wlr.Output` / `wlr.log` etc. come from zig-wlroots 0.20.1 bindings — API mirrors C wlroots; check `zig-pkg/` or `build.zig.zon` hash if signatures look wrong.
- `Output.effectiveBox` (`nile/Nile.zig:371`) not `currentBox` for early placement before first modeset (width==0 guard).
- `Seat.create` no-ops if name exists; `Seat.destroy` silently refuses `"default"` (`nile/Nile.zig:403`).
- `Nile.enableLegacyProtocols` (`nile/Nile.zig:72`) is a no-op — legacy globals were deleted, no `wl.Global.create` remains. Don't try to advertise them without restoring XML + scanner lines from git history.
- `.zig-cache/`, `zig-out/`, `zig-pkg/` are gitignored — never commit them (`.gitignore:1`).
